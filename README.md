This is an application made in Java that mainly focuses on being a study aid for students.

The packages created for the project are: Clock, Pomodoro, and NoteReader.

<h1>Clock</h1>
<p>This class mainly just returns the time, so it can be sent to the clockWindow method in the main.</p>
<h2>Methods</h2>
<h3>DisplayTime</h3>
<p>Returns the current time.</p>

<h1>Pomodoro</h1>
<p>This method manages the pomodoro timer, and sets it up.</p>
<h2>Methods</h2>

<h3>setWorkPomoTimer(int newHour, int newMin, int newSec)</h3>
<p>Setter method for the work duration of the pomodoro.</p>

<h3>setBreakPomoTimer(int newBreakHour, int newBreakMin, int newBreakSec)</h3>
<p>Setter method for the break duration of the pomodoro.</p>

<h3>getWorkPomoHour</h3>
<p>returns value for hours in work duration.</p>
