This repository holds a program that is a study aid for students made entirely in BlueJ.
It features a: Pomodoro timer, clock, note taker, and note displayer

<h1>Projects</h1>

<h2>Pomodoro Timer</h2>
<p></p>

<h2>NoteContainer</h2>
<p>This loads notes that have had their path passed to them.</p>

<h2>NoteTaker</h2>
<p>This takes the notes that the user types, and saves them to a file.</p>

<h2>ClockWindow</h2>
<p>This gets the local time, and displays it for the user to see.</p>

<h1>Packages</h1>

<h2>Clock</h2>
<p>This class gives the current time.</p>
<h3>Methods</h3>
<h4>displayTime()</h4>
<p>returns the current time.</p>

<h2>NoteReader</h2>
<p>This class takes the notes file, and returns the data from the file, as well as takes the users notes as input, and stores them to a file.</p>
<h3>Methods</h3>
<h4>Notetaker()</h4>
<p>Writes the notes to a file</p>
<h4>getNotes()</h4>
<p>returns the notes from a file after the path is passed to it.</p>
<h2>Pomodoro</h2>
<p>This class manages the pomodoro time, mostly though managing the time differences between the two.</p>
<h3>Methods</h3>
<h4>ConvertTime</h4>
<p>Converts the time to miliseconds, one that takes hour and min, and one tha takes sec, hour, and min</p>



This is a submission to the congressional app challenge.

No AI was used in this program whatsoever.
